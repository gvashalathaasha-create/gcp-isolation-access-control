STRATEGIES FOR ISOLATION AND ACCESS CONTROL IN GOOGLE CLOUD PLATFORM
Local HTML/CSS/JavaScript Demonstration

HOW TO RUN:
1. Open this folder in VS Code.
2. Open index.html.
3. Double-click index.html, or use VS Code Live Server if available.
4. Login using:
Tenant A: tenant_a / 1234
Tenant B: tenant_b / 5678
Admin: admin / admin123

This demonstrates authentication, tenant separation, role-based access control and cross-tenant access denial.
NOTE: This is a local prototype/simulation of GCP isolation and access-control concepts. It does not connect to real Google Cloud resources.
